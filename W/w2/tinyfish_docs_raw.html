TinyFish Developer Documentation

Choose the right TinyFish API, authenticate quickly, and start integrating faster

TinyFish gives you five public API surfaces: Agent, Research, Search, Fetch, and Browser. This docs site is organized to help you pick the right one quickly, authenticate once, and move straight to the examples or reference you need. Search and Fetch are free. Agent, Research, and Browser draw from your wallet as they run.
